# AutoScript AI Assistant 🚀

A lightweight, Python-based automation and workspace management utility designed to help developers and students organize local environments and boost productivity instantly.

## Features 🌟
- **Smart File Organizer:** Automatically sorts messy folders into categorized sub-folders based on extensions.
- **System Diagnostics:** Quick retrieval of environment and platform metrics.
- **Clean CLI Interface:** Styled with color-coded terminal prompts for seamless interaction.
